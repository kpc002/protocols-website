Setup environment

Setup of the conda environment for pySCENIC
Author

Maximilian Heeg

Published

November 28, 2022

The environments are needed on both your computer and on the TSCC. Here, we assuse you have already have a working conda on your system. If not, I recommend having a look at Mamba and Mambaforge.

Tip

I prefere using mamba instead of conda as this is a lot faster in resolving the package dependencies.

Create the environment

Create the conda environment by running

mamba env create -f env.yaml
# or
conda env create -f env.yaml

Activate the environment by running conda activate pyscenic. You are now ready to get started.
