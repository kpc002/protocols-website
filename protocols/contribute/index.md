## Via Github

Clone the repository, add a protocol in markdown format and push it. The website in build automatically after every push. The link to the github repo is [github.com/maximilian-heeg/lab-protocols](https://github.com/maximilian-heeg/lab-protocols). Currently this repository is private, so message me if you want access.

If you see a mistake, you can modify the current site my clicking on `Edit this page` on the bottom of each site.

The website is generated by hugo. See their [website](https://gohugo.io) to learn more about the structure of the webpage. In addition, this site used the "Book" theme for Hugo. Further information can be found [here](https://themes.gohugo.io/hugo-book/) and [here](https://github.com/alex-shpak/hugo-book)

## Via Mail

You can always send me a protocol as markdown, word, etc and I will try to include it here.
