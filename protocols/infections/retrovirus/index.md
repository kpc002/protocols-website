# Transfection or how to make a virus stock

{{< hint info >}}
In theory Plat E cells should have the packaging genes to make retrovirus and pCL-Eco should not be needed. However, our Plat E cells have been kept without selection and therefore our protocol recommends to add pCL-Eco nevertheless.
{{</ hint >}}

## Day 1

- Plate Plate E in medium w/o PenStrep 

| Plate | # cells | volume |
|-------|---------|--------|
|10cm dish|2.5 * 10^6|10ml|
|6-well|0.5 * 10^6|2ml|


{{< hint info >}}
Use Medium without PenStrep. This improves the transfection.
{{</ hint >}}
 

## Day 2

- Remove media, add fresh media from Plat E cells
- {{< tabs "day2" >}}
{{< tab "10cm dish" >}} 
- Mix: 
  - 5ug (=50ul) pCL-Eco with 550 ul OptiMEM for each well 
  - Aliquot mix in 15ml falcons -  600ul each (per plate) 
  - Add 10ug plasmid 
- Mix: 
  - 45ul Mirus + 655ul OptiMEM (for each well)
  - Add 700 ul of mix to each falcon  {{< /tab >}}
{{< tab "6 well plate" >}} 
- Mix: 
  - 0.5ug pCL-Eco with 125 ul OptiMEM for each well 
  - Aliquot mix in 1.5ml feppis - 125 each (per well) 
  - Add 2ug plasmid 
- Mix: 
  - 7.5ul Mirus + 117.5ul OptiMEM (for each well)
  - Add 125 ul ul of mix to each eppi  {{< /tab >}}
{{< tab "Other" >}} 
 For other amounts please check the [manual](https://www.mirusbio.com/assets/protocols/ml001_transit_lt1_transfection_reagent.pdf)  
![Table](Mirus.png)
{{< /tab >}}
{{< /tabs >}}
- Incubate at RT for 20 min 
- Add dropwise to cells 

 
## Day 3 
- Take off old media 
- Add new **TCM media**

## Day 4
- Harvest first round of virus (supernatant), keep in fridge 
- Add fresh TCM 

## Day 5 
- Harvest rest of virus, add to virus from previous day. 
- Spin at 1600 rpm for 4 min. 
- Aliquot 2ml in 5 ml Eppis or use directly.
- Freeze at -80°C 

{{< hint info>}}
If planning to use fresh virus, filter with .45um filter
{{</ hint>}}
