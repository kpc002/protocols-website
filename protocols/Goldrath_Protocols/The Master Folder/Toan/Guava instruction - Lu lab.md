# Guava instruction - Lu lab

How to Use Guava for cell count

✔ Sign up the machine in advance.

✔ For the first user of the day, please CLEAN before use! (Click Clean and Shut
Down from Main Menu, then click Start Cleaning, it’ll take ~17min)

✔ Please filter your samples before use!

✔ Always load the tubes (W1-W6) with appropriate buffer (please follow the
instructions shown on Tray Message dialog box!)

✔ For the first time non-Lu lab users, please contact Ling-Li(lllin@ucsd.edu, 858-
822-2734) or Li-Fan before you use the machine.

Procedures:
1. Turn on Guava machine, start CytoSoft software
   Run Clean and Shut Down before use!

2. Dilute samples with Guava Viacount Buffer in a 96 U-bottom plate (minimum total
   final volume per well is 100ul; use 200ul if your cells are in low concentration)

3. Open WorkEdit Software to set up your plate,
   Select the wells, enter the number of Events(the default is 1000)
   þcheck Acquire this sample
   þcheck Wash both capillary and mixer”
   þcheck Mix the samples for 3 secs at High rpm”
   Enter your Dilution Factor and Total Volume of your original sample, save file

4. Click Guava ViaCount from Main Menu
   Click Start worklist
   Load 96 well plate, check tubes (fill the tubes with appropriate solution)
   Select your worklist file and save file (for data file)
   Click Adjust Settings,
   Select one of the samples to adjust the threshold, then
   Click Next Step
   Click Resume to start reading

5. Open Guava Excel software for results

6. If some is going to run the machine within the next half hour, run a quick clean. If
   not, run Clean and Shut down before turning off the machine
