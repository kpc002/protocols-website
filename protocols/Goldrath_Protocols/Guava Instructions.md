**Guava User Instructions**

Hello Guava users, if you use the Guava for any amount of samples (even ONE), you must clean the machine afterwards.

**For a few samples (5 or less):**

\-A quick clean can be done after counting

**For 5 or more samples:**

\-A long clean must be done after counting

**Cleaning Solutions:**

ICF: Instrument Cleaning Fluid (squeeze bottle with green cap)

Water: Please only use ddH2O

**Following cleaning, please check that:**

\-The cleaning vial (clear tube with blue graphics) is filled with ICF to the fill line

\-The waste vial (clear tube with red graphics) is emptied if it is filled past the fill line

**If you are the last user of the day, please shut off the machine and the computer, after you are done.**

Thank you,
