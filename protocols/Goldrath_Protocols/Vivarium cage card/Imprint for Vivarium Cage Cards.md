<span class="underline">To print from Imprint:</span>

1.  There’s a folder labeled “Imprints – Cage Cards Goldrath Lab” at the lab manager bench containing:
    
    1.  Order form
    
    2.  Sample cage cards
    
    3.  8.5 x 11 print of the cage cards pre-cut

2.  Bring the folder over to Imprints and ask them to print according to the information outlined. Provide them the following information:
    
    1.  Index number
    
    2.  Mail code
    
    3.  Location: NSB 5106
    
    4.  Name
    
    5.  Cage card numbers

3.  Provide them the final card size (3x5 HxW) and let them know to use the thickest paper stock they have as well as the final paper color you’ll need

<span class="underline">Ordering from PrintConnect:</span>

1.  Go to: <https://ucsdimprints.myprintdesk.net/DSF/SmartStore.aspx#!/Storefront>

2.  Create a profile with UCSDImprint

3.  After a profile was established, go to home page and begin ordering

4.  In the “featured products” section, choose “Standard Print & Copy” and select “Buy Now” in the pop-out box.

5.  Provide the following information:
    
    1.  “Files”: upload the files you want printed (for cage cards, these can be found in the “imprint” folder in the “lab manager items” folder on the computer under the “8.5 x 11” labels)
    
    2.  “Job name”
    
    3.  “Quantity”: the amount of 1 single-sided 8.5 x 11 of what you wanted to print.
        
        1.  For Cage card, each 8.5 x 11 can be printed into 5 cards, so if you wanted 1000 cards, quantity would be 200
    
    4.  In “specifications” section:
        
        1.  Orientation: portrait
        
        2.  Print in color/sides: black and white: single sided
        
        3.  Media: pick the color for the materials you wanted printed:
            
            1.  For Breeder card: choose “Cover Index 90lbs Blue”
            
            2.  For Yellow card: choose “Cover Index 90lbs Canary”
            
            3.  Choose “8.5 x 11” as size for both
        
        4.  Cutting: choose “specific width and height” in the pop-out and input:
            
            1.  Width: 5 inches
            
            2.  Height: 3 inches
        
        5.  For “call to discuss/request proof/mailing list”, it is okay to choose either as needed
        
        6.  Special Instructions: put “use thickest paper possible”
        
        7.  No need to modify the rest of the options

6.  Choose add to cart when finished and check out with appropriate index number or project number

7.  For cage cards, make separate orders for the 4 separate card types.
