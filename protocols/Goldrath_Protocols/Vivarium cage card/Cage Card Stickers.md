**Cage Card Stickers**

  - Can only use the computer down in the vivarium. There’s usually only one computer in the vivarium that is used to print cage card stickers. This computer is usually set up on a cart along the hallway.

  - The computer is already set up with the program/page for printing stickers with 2 number fields. One for code and one for number of stickers to be printed.
    
      - Enter the code for each vivarium. Need to use the code designated for each vivarium, Pac Hall code will not work on NSB computer and vice versa.
        
          - NSB code: 232512-1
        
          - Pac Hall: 243322-1
    
      - Enter the desired number of stickers to be printed. The bigger the number, the longer it will take to print.
        
          - NSB vivarium tech will usually bring the stickers back into the mouse room but Pac hall tech will not.

  - Bring the stickers back into the mouse room after it’s done printing.
