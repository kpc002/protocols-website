# Setting up PCR

<span class="underline"></span>

1.  Use computer program to calculate correct volumes for PCR mixture based on the number of DNA samples that need to be run. (\#of samples + 2)

2.  Make sure that all reagents are diluted to the concentration used by the program. Also check that you have the correct oligos.

3.  Add 1μl of each DNA sample to separate wells on a PCR plate, check wells.

4.  Combine all reagents other than the Taq and the DNA itself.

5.  Remove the Taq from the freezer and add to the mixture, vortex.

6.  Pipette 24 μl of the mixture into each well containing DNA.

7.  Start desired program on PCR machine. Once the block reaches 95° C, place the plate into the machine and seal with film immediately.

8.  Close lid of machine until program is complete.
