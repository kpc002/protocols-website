## Exercise 4 FoxP3 Reference Control Staining Protocol

|      2. | Incubate/Wash           | ✔                              | -                             |
|      3. | Fix/Perm                | ✔                              | -                             |
|      4. | Wash (with Perm Buffer) | ✔                              | ✔                             |
|      5. | Add IC Ab               | -                              | ✔                             |
|      6. | Incubate/Wash           | ✔                              | ✔                             |
