# Aria Training Checklist

## Pre-training

- [ ] Meet before sorting: determine experience, go over some basic rules
- [ ] Book Aria
- [ ] Email Self-Operator Packet
- [ ] Ask to prepare a SMALL sample for sort practice for second session

## Training

###	System Start Up (p.62-67)
- [ ] Start PC and warm up laser (30 mins)
- [ ] Check fluid (sheath, ethanol, waste)
- [ ] Perform fluidic startup
- [ ] Optimize breakoff
- [ ] Refrigerated fluid circulator


### Checking cytometer performance (p.81-85)
- [ ] CST (reminder: CST beads only good for 20 mins)


### Sorting set up (p.99-103)
- [ ] Accudrop (reminder: Accudrop beads can be re-use)
- [ ] Optimize side stream


### Set Up Experiment (p.142-154)
- [ ] Create experiment and select parameters/colors in cytometer settings
- [ ] Create preliminary plots, labels, and gates 
- [ ] Use full-stained cells to adjust FSC/SSC to place population on scale
- [ ] Use full-stained cells to adjust PMT voltages if needed
- [ ] Optional: Create compensation
- [ ] Set up sort layout
- [ ] Sort
- [ ] Optional: purity check
- [ ] Data transfer


### Clean Up, Shutdown and Trouble shooting
- [ ] Clean with 3 clean reagent
- [ ] Standby mode
- [ ] Shutdown program
- [ ] User account
- [ ] Add to user list
- [ ] How to deal with clog
